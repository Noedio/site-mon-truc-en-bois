Réglages avancés
Comment obtenir une clé d'accès ?
  1. Ouvrez github.com/settings/personal-access-tokens/new (connecté à votre compte GitHub).
  2. Token name : « Admin site » — Expiration : 1 an (ou plus).
  3. Repository access : Only select repositories → choisissez site-mon-truc-en-bois.
  4. Permissions → Repository permissions : Contents, Secrets et Variables sur Read and write, Actions sur Read-only (les trois derniers servent à installer le serveur des commandes).
  5. Cliquez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ici.
